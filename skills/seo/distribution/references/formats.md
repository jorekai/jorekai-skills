# Formats

## X thread

- 5–8 posts. Post 1: keyword in the first line, the strongest claim or number, no link. Posts 2–7: one sub-point each, one line of evidence (`[OWN NUMBER]`, `[SCREENSHOT]`). Last post: the takeaway and the URL.
- Under 280 characters per post; numbers as digits; one idea per post.
- Repost the first post as a quote 2 days later with a second angle.

## LinkedIn post

- 150–250 words. First line: keyword plus outcome; it must survive the "see more" cut on its own.
- Short lines, blank line between them. One story or number from the page, then 3 bullet takeaways, then a question.
- URL at the end, or in the first comment with a line in the post saying so.
- No hashtags beyond 3.

## Reddit answer

- Pick a subreddit where the question is actually asked; find a live thread (WebSearch `site:reddit.com [keyword]`, sorted by recent) with the question the page answers. Prefer threads that already appear in Google's "Discussions and forums" box for the keyword: the answer then sits on page 1.
- Answer the question completely in the comment: steps, numbers, caveats. 100–300 words.
- Link as the last line, framed as "longer write-up with screenshots here", only if the comment is already complete without it.
- Account history matters: a fresh account posting links is removed. Comment usefully elsewhere first.

## Reply under a bigger post

- 2–4 sentences that add a fact, a number, or a correction the post lacks.
- Link only if the reply's point depends on it.

## Trend-led post

- Line 1: the trend, named as people search it.
- Line 2: the bridge to the page's topic.
- Lines 3–6: the page's strongest point applied to the trend.
- Last line: the URL.
