# Domain naming

For a new domain only. An existing brand keeps its domain; a migration costs more ranking than any name gains.

- TLD: `.com`, `.org`, `.dev`, `.ai`, `.io`. Country TLD (`.de`, `.at`, `.ch`) when audience and language are one country.
- Keyword-like name while the brand is unknown (`osssoftware.org`, not `zyx-labs.org`).
- At most 14 letters. Letters only: no hyphen, no underscore, no digits.
- One topic per domain. A second topic gets its own domain or lives in a subfolder. Google states it treats subdomains and subfolders the same; keep related content on one host anyway, because internal links and crawl budget are then shared.
- Decide `www` vs non-`www` once; the other host 301s to it. Same for `http → https` and trailing slash.
- Check history before buying: Wayback Machine snapshots, backlink profile in a backlink index, `site:` search. Google's expired-domain-abuse policy treats reusing an old domain's authority for unrelated low-value content as spam ("it's fine to use an old domain name for a new, original site that's designed to serve people first"), and past manual actions can persist; a domain with a foreign history is a liability, not an asset.
